Copyright Zack Scholl; preserve the copyright notices in individual files. The plugin is built from the firmware headers in this repository, rather than an independently implemented DSP model.

- **PCG random generator:** `lib/pcg_basic.c` and `lib/pcg_basic.h`, Copyright 2014 Melissa O'Neill, Apache License 2.0. The full license is included in `licenses/Apache-2.0.txt`; the original notices remain in the corresponding source archive.
- **Ectocore panel artwork:** `res/ectocore.svg` is adapted from the supplied Ectocore hardware design (`ectocore.svg`, `Panel8hpFINAL.svg` layer). It preserves the original outlined lettering, illustrations, runes, and branding. The Rack asset removes the surrounding canvas, mock controls, drill guides, embedded thumbnail, and unsupported MIDI legend. Live controls remain editable vector drawing code in `src/Ectocore.cpp`; no product photographs are embedded.
- **EZEPTOCORE panel artwork:** `res/ezeptocore.svg` is adapted from the supplied `ezeptocore.svg`. It preserves the black-and-gold artwork, decorative traces, icons, and Infinite Digits / Maneco Labs branding. Mock controls are replaced by live Rack widgets; the two small supplied footer marks are converted to vector contours.
- **Monaspace Neon Bold:** the EZEPTOCORE SVG's remaining text was outlined using the font from [GitHub Next's Monaspace project](https://github.com/githubnext/monaspace), licensed under the SIL Open Font License 1.1. The license and copyright notice are included in `licenses/Monaspace-OFL.txt`. No font installation is required by the finished panel.
- **Rune drawings:** the additional `res/rune1.svg` through `rune7.svg` assets derive from this repository's `sample-manager/Resources/Artwork/` drawings. Rack copies change the size and stroke color; the Ectocore panel now includes the hardware SVG's own runes.
- **Odin Rounded Regular:** font by Frank Hemmekam, Copyright 2013, retained among the bundled resources. Copied unchanged from `sample-manager/Resources/Fonts/odin-rounded.regular.otf`, reconstructed from the original website's WOFF tables. The Ectocore artwork now contains outlined lettering. Font attribution, provenance, and embedded notices are included in `licenses/Odin-Rounded-NOTICE.txt`.
- **VCV Rack:** the plugin links to the installed Rack runtime and uses its SDK interfaces, NanoVG, Jansson, Speex sample-rate converter, and component library. The SDK and Rack executable are not redistributed in this package. SDK licenses are supplied with the official SDK download: https://vcvrack.com/downloads/.

No user samples, factory sample packs, sample-manager binary, pretrained models, or proprietary artwork are included. Synthetic test signals are generated by the test suite.

Distribute the matching `InfiniteDigits-2.0.0-source.tar.gz` alongside binary packages. Generate it from the same working tree with `python3 rack/scripts/source.py`; its SHA-256 manifest identifies the included source files, including local changes. This repository has not assigned a release tag to this initial implementation.
